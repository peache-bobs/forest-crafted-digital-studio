# Forest Crafted Digital Studio

Создай законченный адаптивный русскоязычный сайт-портфолио независимого разработчика для заказчиков. Временный бренд «Разработка / под задачу» без выдуманного имени. Художественное направление: туманный хвойный лес, старый серый камень, мох, приглушённый болотный зелёный. Референсы пользователя: серый готический каменный собор на фоне туманных гор; высокие деревья в сером тумане; болотный ландшафт с тонкими техническими схемами. Используй эти мотивы как настроение, не копируй скриншоты с интерфейсом. Палитра #101915 #1C2B23 #353D38 #8D9790 #D8DDD7. Без кислотных цветов/фиолетового. Премиальная редакционная композиция, крупная кириллическая типографика, простор, тонкие линии, маленькие моноширинные индексы, атмосферное фото леса с затемнением и тонкими схемными линиями в hero, аккуратные анимации с reduced-motion.

Hero: «Сайты, боты и автоматизация. Под задачи вашего бизнеса.» Подзаголовок от первого лица: «Помогаю превратить идею в работающий инструмент: от Telegram-бота до системы управления заведением.» Кнопки «Смотреть проекты» и «Обсудить задачу» ведут к соответствующим секциям. Навигация Проекты / Услуги / Подход / Контакт.
Услуги 6: Telegram-боты (заказы, запись, уведомления, поддержка); Сайты и веб-приложения (лендинги, каталоги, личные кабинеты); Автоматизация ресторанов и кафе (QR-меню, бронирования, заказы, отчёты); Интеграции и CRM (связать формы, таблицы и сервисы); Внутренние инструменты (дашборды, учёт, управление задачами); AI-помощники (база знаний и типовые обращения). Уверенный текст о предлагаемых возможностях, но без выдуманных достижений, клиентов, стажа, отзывов или обещаний процентов роста.
Проекты: подготовь красивую секцию из 3 визуальных карточек с нейтральными абстрактными интерфейсами (бот, сайт, автоматизация), чётко помеченных «Место для проекта» и текстом «Описание и ссылка появятся здесь». Это placeholders, не реальные кейсы. Не добавляй фальшивые работающие ссылки. Данные проектов вынеси в простой массив для последующего заполнения реальными ссылками пользователя.
Подход: Разбираюсь в задаче / Предлагаю решение / Собираю и проверяю / Помогаю с запуском.
Контакт: «Обсудим вашу задачу»; контакт пока неизвестен, покажи честный текст «Контакт для связи скоро появится», без выдуманного Telegram. Можно сделать полезный локальный мини-бриф: тип проекта, описание, кнопка «Скопировать бриф», реальное копирование в буфер с понятной обратной связью, без имитации отправки. Никакого backend или регистрации не нужно.
Проверь мобильную версию, навигацию, контраст, копирование брифа и сборку. Создай сайт сейчас, не задавай уточняющие вопросы.
